# rydberg_blockade_array

- **Date**: 2026-05-12
- **Theme**: Quantum computing, Rydberg atoms, dipole blockade, collective excitations.
- **Visual Impression**: A precise 3D grid of neutral atoms (dim white points) sits in a dark vacuum. Suddenly, one atom is laser-excited into a Rydberg state, erupting in a blinding Neon Orange glow. This creates a "blockade" sphere—a ghostly, translucent orange shell—within which no other atom can be excited. Waves of these excitations ripple through the array, creating a complex, shifting pattern of light and shadow that illustrates the principle of the Rydberg blockade.
- **Technique**: 3D grid simulation. Particles represent atoms. A dynamic "excitation" field pulses through the grid. Blockade logic: $E_i = 1$ if $V_i > Threshold$ and $\sum E_j / r_{ij} < limit$. Multi-pass additive rendering with glowing shells. Palette: "Ultramarine / Neon Orange / Star-White". 12s 4K/60fps MP4 (1080p source).
