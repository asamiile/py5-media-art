# kinetic_abstract_geometric_metaballs_2d

40 glowing, squishy "metaballs" (isosurfaces) drifting, merging, and splitting organically in 2D space, mimicking liquid metal.

## Techniques

Evaluates the metaball field over a dense grid using NumPy. Instead of a solid threshold, it maps the field intensity to hue and sine-wave based contours for a fluid rainbow interference effect.

## Palette

Highly saturated liquid rainbow colors mapped to the field strength, with glowing bright cores and dark drop-offs.
