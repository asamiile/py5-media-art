# geometric_interference_bloom_3d

**Date**: 2026-05-25
**Theme**: A microscopic view of an artificial geometric bloom.
**Technique**: Concentric 3D polygons scaling and rotating via a 2D interference ripple, rendered with additive blending.

## Description
A mesmerizing animation of concentric 3D polygons that bloom and ripple rhythmically. As the shapes scale and rotate, the sine wave interference patterns combine with additive blending to create a radiant, microscopic floral structure that breathes gracefully over time.

## Format
Animation (15s @ 60fps)
