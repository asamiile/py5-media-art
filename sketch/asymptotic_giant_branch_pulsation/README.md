# asymptotic_giant_branch_pulsation

A rhythmic, delicate visualization of the late-stage evolution of a low-mass star, shedding its outer layers into the cosmos.

## Theme
Stellar evolution, AGB stars, thermal pulses, planetary nebula precursor, stardust.

## Technique
3D shell ejection simulation. A central core undergoes periodic pulses every 180 frames, triggering the expansion of nested, concentric shells of 15,000 tracers each (up to 150,000 total). Features "convective" surface variations, manual 3D-to-2D projection, multi-pass additive blending, and a "Rose Quartz / Burnt Orange / Pale Silver" palette.

## Description
Concentric, shimmering shells of stardust expand slowly from a pulsing stellar core. Each layer is etched with the memory of convective cells on the star's surface, creating a delicate, layered cocoon of rose and orange light that eventually fades into the pale silver of the interstellar void.
