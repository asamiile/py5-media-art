# kinetic_procedural_neon_cityscape_grid_2d

A top-down view of a futuristic, glowing city grid where data packets (particles) flow along the streets. The streets form organically using a space colonization algorithm or recursive subdivision.

## Tech
- **Library**: py5, NumPy
- **Concept**: Recursive subdivision, procedural generation, graph networks, particle flow.
- **Palette**: Cyberpunk—dark violet, neon pink, and cyan.
