# kinetic_physics_gravitational_lensing_accretion_disk_3d

A simulation of an accretion disk around a binary black hole system. 150,000 glowing particles orbit the singularities, getting accelerated, color-shifted by speed, and swept into glowing rings.

## Techniques

O(N) gravity calculation from two central moving point masses using NumPy. Particles start in a disk and are slowly pulled in or ejected.

## Palette

Extremely bright orange, yellow, and white around the cores, with cyan and purple ejections.
