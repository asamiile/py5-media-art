# cellular_automata_coral_growth_2d

An animated 15s sequence of vibrant branching coral growth radiating from the base, using procedurally generated fractal L-systems.

## Theme
A vibrant simulation of branching coral growth radiating from the base, taking on vibrant rainbow hues that shift over time.

## Technique
Procedurally generated recursive fractal trees. The branching structure is calculated using recursive functions with branching angles modified by continuous Perlin noise (`py5.os_noise`) and varying stroke weights. This gives a very organic and undulating appearance similar to coral in sea currents.
