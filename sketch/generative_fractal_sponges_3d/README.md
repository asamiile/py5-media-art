# generative_fractal_sponges_3d

A continuously rotating Menger Sponge fractal that grows and pulses in a 3D isometric view.

![Preview](generative_fractal_sponges_3d_p1.png)

## Details
- **Date**: 2026-06-20
- **Technique**: Recursive 3D boxes drawing a Menger sponge up to depth 3, with additive neon blending and an oscillating camera.
- **Format**: Animation (10s @ 60fps)
