# bioluminescent_crystalline_fractal_tree_3d

## Theme
An ethereal, bioluminescent crystalline tree growing and branching in a dark void.

## Technique
3D Recursive branching (L-system) using `py5.push_matrix()` and `py5.pop_matrix()`. The angles of the branches slowly sway using OpenSimplex noise. The tree glows using additive blending, with stroke weights tapering off at the branch tips.

## Color palette
- Background: Very dark indigo
- Dominant: Luminous violet / magenta
- Secondary: Electric cyan at the branch tips
- Mood: Serene / Magical / Ethereal

## Format
Animation (10s @ 60fps)
