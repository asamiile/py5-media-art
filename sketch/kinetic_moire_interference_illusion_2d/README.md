# kinetic_moire_interference_illusion_2d

A hypnotic, chromatic optical illusion where dense, overlapping concentric wave patterns continuously shift and interfere with each other, creating intense moiré patterns that appear to pulse and move in impossible directions.

## Technique

Additive color blending of four sweeping geometric rings (Red, Green, Blue, Yellow). Sine wave modulation drives the line thickness and center coordinates to create fluid, overlapping moiré interference patterns on a high-contrast dark canvas.

## Output

Animation (20s @ 60fps)
