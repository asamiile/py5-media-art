# kinetic_oregonator_bz_waves_2d

An animated 2D visualization of the Belousov-Zhabotinsky (BZ) reaction-diffusion equations modeled using the three-variable Oregonator system.

## Details

- **Date**: 2026-08-11
- **Theme**: An alien landscape of pulsing, chemical clocks, where waves of excitation propagate, curl, and self-replicate in a bioluminescent sea.
- **Technique**: Vectorized 2D numerical integration of the Tyson-Fife Oregonator reaction-diffusion PDEs using finite-difference Laplacian and Euler sub-stepping. Features dynamic spiral initial seeding and color mapping representing chemical components (activator, inhibitor, and reaction front).
- **Color Palette**:
  - Background: Obsidian Abyss (`#050508`)
  - Dominant: Bioluminescent Emerald (`#50c878`)
  - Secondary: Neon Amethyst (`#9966cc`)
  - Accent: Coral Pink (`#ff7f50`)
- **Format**: Animation (60fps)
