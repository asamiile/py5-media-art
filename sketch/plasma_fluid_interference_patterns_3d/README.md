# plasma_fluid_interference_patterns_3d

## Details
- **Date**: 2026-06-05
- **Format**: Animation (10s @ 60fps)
- **Theme**: A flowing 3D field of interacting sine waves creating interference patterns that resemble glowing liquid plasma, viewed from a rotating camera.

## Technique
A dense grid of 3D `py5.POINTS`. The Z-height and color of each point are calculated by summing multiple high-frequency sine and cosine waves offset by time and distance from multiple moving "droplet" origins, creating dynamic interference patterns.
