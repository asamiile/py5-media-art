# kinetic_abstract_geometric_truchet_tiles_maze_2d

A constantly evolving Truchet tile maze. Tiles rotate smoothly, continuously creating and destroying winding geometric paths.

## Techniques

A grid of tiles where each tile contains curved arcs. A 2D array stores the continuous rotation state. A 2D sine/cosine noise wave passes over the grid, triggering smooth rotations between 0 and 90 degrees.

## Palette

Neon cyber-colors mapped to the spatial coordinates, leaving a faint glowing trail behind moving paths.
