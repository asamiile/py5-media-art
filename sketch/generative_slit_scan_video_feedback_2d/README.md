# generative_slit_scan_video_feedback_2d

**Date**: 2026-07-05
**Type**: Animation (10-30s @ 60fps)

## Concept
Emulating the classic slit-scan technique combined with video feedback loops. A central rotating object (or moving shape) is continuously sampled in horizontal slits. These slits are then fed back into the main canvas with slight scaling and color shifts, creating a tunnel-like, melting temporal smear.

## Techniques
Screen pixel sampling and offset copying.

## Palette
Retro glitch. High contrast black, white, and intense primary colors (red, green, blue).
