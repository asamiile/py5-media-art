# chromatic_glass_monoliths_3d

## Creative Brief

### Theme
Floating, brutalist glass monoliths rotating slowly in an endless neon-lit canyon, reflecting vibrant accents.

### Technique
3D generation of large transparent `py5.box` elements with slow rotational matrices, lit by colored point lights and directional lights.

### Color palette
- Background: Very dark indigo
- Dominant (60%): Deep cyan
- Secondary (30%): Saturated magenta
- Accent (10%): Warm gold
- Mood: Neon/Cyberpunk but slow and majestic

### Visual impression (first 3 seconds)
Majestic, slow rotation of immense glass structures catching colorful light.

### Format
Animation (15s @ 60fps)

### Rationale
A massive, slow, architectural animation using lights to introduce a different pacing and scale compared to recent chaotic particle systems.
