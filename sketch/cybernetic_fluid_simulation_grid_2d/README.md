# cybernetic_fluid_simulation_grid_2d

A 2D liquid simulation represented through a strict cellular grid. The fluid behaves like glowing plasma, shifting colors as it flows through the cells.

## Details

- **Type**: 2D animation
- **Length**: 10 seconds (60fps)

## Technique

An Eulerian fluid simulation approximation using multi-octave 3D noise to drive flow density across a low-resolution grid, rendered as high-contrast glowing rectangles with additive blending.
