# kinetic_particle_attractor_strange_2d

**Date**: 2026-07-21
**Type**: Animation (900 frames, 60fps)

## Concept
Millions of particles mapping out a mathematical strange attractor that slowly morphs over time, resembling a dense, glowing, intricate ribbon in a void.

## Techniques
A vectorized Clifford Attractor algorithm is applied to 1,000,000 particles using NumPy to achieve real-time performance in pure Python. The attractor's parameters (a, b, c, d) gently drift over time driven by Perlin noise, causing the entire structure to unfold and transform seamlessly. Very high alpha values and additive blending build up intense, solid-looking three-dimensional structures from the sparse points.

## Palette
White-hot cores fading into soft golds, ambers, and purples at the fringes, set against a deep black void with a very slow trailing fade.
