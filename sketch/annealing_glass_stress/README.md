# annealing_glass_stress

## Theme

Invisible thermal stress in moving glass sheets becomes visible as a quiet factory ritual.

## Technique

This 10-second 60fps animation renders an annealing line viewed through crossed polarizers. Glass panes move across rollers while layered interference contours, heat-zone glows, stress cracks, and diagnostic meters translate material strain into restrained cyan, violet, and amber light.

## Outputs

- `annealing_glass_stress_p1.png` - midpoint preview image
- `annealing_glass_stress.mp4` - generated animation output
