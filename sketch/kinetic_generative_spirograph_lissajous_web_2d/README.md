# kinetic_generative_spirograph_lissajous_web_2d

A mesmerizing complex web of lines generated by multiple interlocking Lissajous/harmonograph curves. The moving "pen" connects back to its own history, creating intricate, glowing geometric thread-art.

## Techniques

Computes a continuous path using four combined sine/cosine frequencies with evolving phase shifts. The current point is connected via lines to older points in a rolling history buffer at specific phase intervals, forming a structural web.

## Palette

Deep magenta to cyan gradients with additive blending over a dark purple background, mimicking glowing thread or laser light.
