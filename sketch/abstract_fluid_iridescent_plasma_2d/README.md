# abstract_fluid_iridescent_plasma_2d

## Metadata
- **Date**: 2026-06-28
- **Theme**: A dynamic fluid simulation visualizing an iridescent, plasma-like energy field
- **Technique**: The sketch uses a particle system of 8,000 points moving through a 2D vector flow field. The flow field is generated by combining multiple scales of OpenSimplex noise (`py5.os_noise`) mapped to directional angles. Particles are drawn using `py5.ADD` blend mode to create a glowing, cumulative light effect. Particle hues are dynamically mapped based on their current velocity and time, producing vibrant, shifting iridescent colors. Particles have individual lifetimes and reset upon fading or leaving the screen to maintain a continuous, flowing composition.

## Concept
A dynamic fluid simulation visualizing an iridescent, plasma-like energy field. Thousands of glowing particles flow through a chaotic vector field driven by overlapping noise functions, creating an ethereal, luminous dance that resembles superheated gas or liquid light.
