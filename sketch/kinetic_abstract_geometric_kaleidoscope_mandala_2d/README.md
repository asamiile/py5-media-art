# kinetic_abstract_geometric_kaleidoscope_mandala_2d

A slowly rotating, procedurally generated mandala that functions like a kaleidoscope.

## Techniques

Generates geometric shapes (pentagons) that move organically using Perlin noise. The coordinate space is divided into 12 radial segments, mirrored and duplicated symmetrically using `py5.push_matrix`, `py5.rotate`, and `py5.scale`. Additive blending and motion blur create a glowing, hypnotic effect.

## Palette

Rich golds, ambers, and deep crimsons against a dark background, evoking mystical or cosmic energy.
