# kinetic_swift_hohenberg_convection_2d

Non-equilibrium convective roll patterns generated by a 2D Swift-Hohenberg solver coupled with divergence-free advection.

## Concept
This artwork captures the fingerprints of Rayleigh-Bénard convection rolls and instabilites. By coupling the Swift-Hohenberg PDE (which models convective pattern formation near threshold) with a divergence-free advection velocity field, the convective rolls drift, shear, and reorganise dynamically, forming complex labyrinthine textures.

## Techniques
- **Swift-Hohenberg Fourth-Order PDE**: Solves $\frac{\partial u}{\partial t} = \epsilon u - (\nabla^2 + q_c^2)^2 u - u^3$ under stable CFL constraints.
- **Divergence-Free Advection**: Computes convective advection velocities using a stream function $\psi$: $v_x = \frac{\partial \psi}{\partial y}$, $v_y = -\frac{\partial \psi}{\partial x}$.
- **Glow & Gradient Mapping**: Maps positive state variables $u$ to warm glowing ember oranges/golds, negative values to deep obsidian blues, and shear boundaries to electric cyan.
- **Robust Pixels Fallback**: Uses standard flat 1D pixels array as a robust fallback for systems where `np_pixels` OpenGL context is not fully initialized.
