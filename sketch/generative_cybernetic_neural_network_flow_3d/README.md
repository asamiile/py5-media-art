# generative_cybernetic_neural_network_flow_3d

- **Date**: 2026-07-04
- **Type**: Animation (900 frames, 60fps)

## Concept
A 3D cybernetic neural network where thousands of data packets traverse the synapses of a giant geometric brain, slowly rotating in the void.

## Techniques
Generates a 3D random geometric graph of 400 nodes within a sphere. A custom software 3D projection engine maps the 3D coordinates to a 2D plane, ensuring absolute stability at 4K resolution without relying on hardware OpenGL (which can crash the JVM). 4,000 data packets move continuously along the network edges. An emergent glitch in the pathfinding logic causes packets to sometimes streak through the surrounding void, adding a beautiful hyper-speed aesthetic.

## Palette
Dark cyberpunk aesthetic. Pitch black void, faint dark purple edges, and bright neon cyan and pink data packets.
