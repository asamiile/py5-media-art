# kinetic_organic_bubble_foam_packing_2d

An organic, continuous circle packing algorithm. Circles spawn and grow until they hit each other. Each has a finite lifespan before popping, leaving space for new circles and creating a boiling, foam-like kinetic texture.

## Techniques

Uses optimized NumPy broadcasting to check collisions between 1,500 growing bubbles every frame. Rendered using transparent fills and bright edges.

## Palette

Deep ocean blues and bioluminescent cyan against a dark copper background, resembling sea foam or alien soap bubbles.
