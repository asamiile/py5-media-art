# kinetic_optical_flow_glitch_typography_2d

A wall of text that acts like a fluid. Letters push and pull each other based on hidden optical flow vectors. The typography distorts and glitches out like a broken display when turbulence gets too high.

## Tech
- **Library**: py5, NumPy
- **Concept**: Fluid typography, optical flow distortion, chromatic aberration glitch.
- **Palette**: Monochrome black/white with bright red/cyan glitch channels.
