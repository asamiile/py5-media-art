# kinetic_math_topological_contour_flow_2d

A generative topographic map where 15,000 glowing particles continuously trace the contour lines of an unseen, slowly shifting 3D Perlin noise landscape.

## Techniques

Computes the 2D gradient of a Perlin noise field and rotates the vectors by 90 degrees to find the contour direction. Particles flow perfectly perpendicular to the gradient, drawing out intricate, shifting topographic rings and valleys.

## Palette

"Neon Topography": Electric purple and bright pink particles leaving glowing trails against a very dark, near-black background.
