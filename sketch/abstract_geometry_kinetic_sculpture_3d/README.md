# abstract_geometry_kinetic_sculpture_3d

An animated 15s sequence of a floating, slowly expanding and contracting geometric object made of interlocking transparent cubes and pyramids that rotate in a complex synchronized pattern.

## Theme
A floating, slowly expanding and contracting geometric object made of hundreds of interlocking transparent cubes and pyramids that rotate in a complex synchronized pattern.

## Technique
3D scene using `py5.P3D`. Multiple nested push_matrix and rotate operations driven by sine waves of varying frequencies to create a mesmerizing kinetic mechanism. Lighting is directional with a mix of cyan and amber. Elements are spherically distributed using Fibonacci lattice-inspired angular math.
