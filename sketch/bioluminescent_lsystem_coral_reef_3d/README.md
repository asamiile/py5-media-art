# bioluminescent_lsystem_coral_reef_3d

An intricate, procedural L-system coral reef growing organically in a deep oceanic abyss. The entire structure pulses with bioluminescent colors and sways gently, as if affected by invisible underwater currents.

## Technical Details

- **Framework**: py5 (P3D mode)
- **Resolution**: 3840x2160 (4K)
- **Framerate**: 60 FPS
- **Duration**: 15 seconds
- **Techniques**:
  - 3D recursive branching (L-system)
  - Organic motion via 3D Perlin noise controlling branch rotation angles
  - Volumetric lighting and smooth sphere meshes (`sphere_detail(8)`)
  - Color lerping based on recursion depth for glowing yellow/cyan tips
