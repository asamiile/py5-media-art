# supernova_nucleosynthesis_nebula

A violent yet majestic expansion of a dying star, scattering heavy elements into the cosmic void.

## Theme
Stellar evolution, supernova explosions, heavy element creation (nucleosynthesis), nuclear physics, beautiful night sky.

## Technique
3D blast wave simulation using an expanding shell of 80,000 particles with stochastic cooling and turbulence. Each particle represents a group of heavy elements color-coded by their emission properties. Features manual 3D-to-2D projection, multi-pass additive blending, and a "Deep Gold / Neon Violet / Star-White" palette.

## Description
A central core collapses and rebounds, sending a shimmering, variegated nebula of precious metals and stardust into the cosmic dark. The explosion expands and cools, revealing a complex web of golden light and violet ionization fronts that slowly fill the obsidian frame.
