# spinodal_decomposition_nebula

- **Date**: 2026-05-13
- **Theme**: The spontaneous separation of two primordial fluids as the universe cools, creating a vast, intricate web of matter and void.
- **Technique**: Cahn-Hilliard equation simulation on a 256x256 grid, scaled to 4K using LANCZOS. Visualizes phase separation (spinodal decomposition) with a spectral mapping from obsidian to solar white.
- **Palette**: Obsidian / Deep Amethyst / Electric Cyan / Solar White
- **Format**: Animation (15s @ 60fps)

## Description

A shimmering, uniform mist of purple and cyan slowly curdles and separates into a majestic, glowing sponge-like network of light threads, leaving vast dark voids in between. This work captures the topological emergence of structure from primordial chaos.
