# harmonograph_slate_caustics

## Overview
- **Genre**: Physical / Micro-Kinetic
- **Composition Archetype**: Full-Canvas Polyptych / Rhythmic Matrix
- **Motion Archetype**: Persistent Trail Accumulation & Decay
- **Tonal / Palette Family**: Mid-Tone Atmospheric Dusk / Celadon Slate (`#2c3840`, `#8ab2b4`, `#e8e3d8`, `#e29434`)
- **Format**: Animation (21s @ 60fps, 3840×2160)

## Concept & Technique
An edge-to-edge hierarchical polyptych of 48 subdivided acoustic harmonograph cells across a mid-tone atmospheric dusk slate field (`#2c3840`). In each cell, coupled tri-frequency rotary pendulums trace evolving Lissajous-caustic envelopes in soft chalk, warm amber-ochre, and misty celadon-teal over a persistent translucent frame-decay buffer (`fill(44, 56, 64, 7)`).
