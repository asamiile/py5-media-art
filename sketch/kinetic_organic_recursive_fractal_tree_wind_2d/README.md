# kinetic_organic_recursive_fractal_tree_wind_2d

A majestic recursive fractal tree that sways organically as if blowing in a strong wind, generating thousands of dynamic branches.

## Techniques

A deeply recursive branching algorithm (depth 12) combining spatial coordinates and time via 1D Perlin noise to calculate dynamic wind angles. Additive blending creates a glowing effect at the denser, overlapping tips of the tree.

## Palette

"Autumn glowing": Dark brown, thick trunks fading into bright red, orange, and yellow glowing tips against a deep forest green background.
