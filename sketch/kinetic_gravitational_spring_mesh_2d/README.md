# kinetic_gravitational_spring_mesh_2d

**Date**: 2026-07-21
**Type**: Animation (900 frames, 60fps)

## Concept
A fragile geometric structure being slowly pulled apart by invisible gravitational forces. Delicate white/cyan lines form a mesh that stretches and warps near orbiting attractors.

## Techniques
Spring-mass physics system mapped to a 2D mesh, perturbed by orbiting "black hole" attractors that rip the connections when stretched too far.

## Palette
Deep navy background with glowing cyan and magenta lines stretching to their breaking point.
