# raster_extrusion_corridor

## Overview
- **Genre**: Signal / Glitch / Digital Artifacts
- **Composition Archetype**: 3D Sculptural / Volumetric Space (P3D)
- **Motion Archetype**: Spatial Camera / Depth Traversal
- **Palette Family**: Stark Constructivist High-Contrast
- **Format**: Animation (`16s (960 frames @ 60fps)`, 3840×2160 4K)
- **Technique**: `P3D + PostFX`

## Concept & Visual Architecture
`raster_extrusion_corridor` is a true P3D volumetric signal sculpture in which 28 depth-stacked raster deflection ribbon curtains and 180 quantized phase-slip voxel blocks are extruded into three-dimensional perspective space across a stark constructivist carbon-black ground (`#0d0f14`).

An orbiting perspective camera traverses the volumetric depth corridor while horizontal scanline shears and staircase quantization steps deform the 3D raster planes in crisp bone white (`#f3f0e8`), signal vermilion (`#e83424`), international ultramarine (`#1c3ed6`), and cadmium ochre (`#f2b218`).
