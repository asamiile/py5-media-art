# kinetic_ferrofluid_magnetic_spikes_2d

A 2D simulation of ferrofluid reacting to dynamic magnetic fields, forming intricate, spiky, 3D-like geometric shapes that morph over time.

## Tech
- **Library**: py5, NumPy
- **Concept**: Ferrofluid, magnetic spikes, fake 3D depth, 2D noise.
- **Palette**: Glossy metallic black/obsidian spikes against a glowing crimson and orange background.
