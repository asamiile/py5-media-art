# celadon_soliton_estuary

## Overview
- **Genre**: Atmospheric / Painterly / Color Field
- **Composition Archetype**: Asymmetric Off-Center Tension
- **Motion Archetype**: Directional Advection & Traveling Wavefronts
- **Tonal / Palette Family**: Mid-Tone Atmospheric Dusk / Celadon Slate (`#2c3840`, `#3d4e48`, `#749092`, `#e6e1d6`, `#df9238`)
- **Format**: Animation (15s @ 60fps, 3840×2160)

## Concept & Technique
Internal soliton wave packets radiate from an off-center tidal mouth near the lower-left golden-ratio focal zone and propagate diagonally across a mid-tone celadon-slate dusk field (`#2c3840`–`#3d4e48`). A custom domain-warped fBm and $\operatorname{sech}^2$ soliton shader renders the traveling wave crests and warm amber silt shimmer, while 240 soft chalk-mist and amber drift ribbons ride the phase fronts via vectorized `py5.QUADS`.
