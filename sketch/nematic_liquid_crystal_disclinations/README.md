# nematic_liquid_crystal_disclinations

A serene yet complex visualization of hidden topological order in a nematic liquid crystal.

## Theme
Liquid crystals, topological defects, disclination lines, soft matter physics, beautiful night sky.

## Technique
3D tensor field simulation (simplified director field) where orientation is influenced by moving defect centers (vortices). Features 40,000 tracers advected along the director field, creating silken filaments that reveal the underlying topological structure. Rendered with manual 3D-to-2D projection, multi-pass additive blending, and a "Spectral Blue / Pearl / Ionized Amethyst" palette.

## Description
Silken filaments of pearl and blue light weave through the obsidian void, revealing the tangled topological defects of a liquid crystal phase as it relaxes toward equilibrium. The swirling motions trace the hidden singularities of the director field, appearing like cosmic threads dancing in the dark.
