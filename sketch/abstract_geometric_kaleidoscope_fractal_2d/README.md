# abstract_geometric_kaleidoscope_fractal_2d

## Theme
A glowing, infinitely unfolding geometric fractal that mimics the shifting mirrors of a kaleidoscope.

## Technique
Uses standard 2D recursive rendering. At each level of recursion, the shape splits into 6 branches that rotate and translate based on time and their recursive depth. The ADD blend mode creates intense glowing intersections where the semi-transparent layers overlap.
