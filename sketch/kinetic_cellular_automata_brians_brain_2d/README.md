# kinetic_cellular_automata_brians_brain_2d

A visualization of the "Brian's Brain" cellular automaton, which creates spectacular expanding diamond-like patterns reminiscent of firing neural synapses.

## Techniques

Vectorized 2D cellular automata using SciPy's 2D convolution over a 3-state grid (Ready, Firing, Refractory). The grid is continually stimulated by random noise spikes to keep the pattern evolving endlessly.

## Palette

Firing cells are brilliant cyan, Refractory are deep purple, and Ready are dark blue space background.
