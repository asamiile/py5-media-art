# kinetic_cymatic_resonance_patterns_2d

Simulated Chladni plates (cymatics). Sand particles organizing themselves into intricate geometric mandalas driven by interfering standing waves.

## Tech
- **Library**: py5, NumPy
- **Concept**: Cymatics, Chladni plates, standing waves, resonance, particle physics.
- **Palette**: Deep matte black plate with pure gold, glowing particles accumulating over time.
