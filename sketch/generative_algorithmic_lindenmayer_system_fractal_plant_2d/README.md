# generative_algorithmic_lindenmayer_system_fractal_plant_2d

- **Date**: 2026-06-24
- **Theme**: An animated 2D L-system fractal plant. A glowing, intricate fractal tree grows dynamically from the bottom, its branches swaying to a virtual breeze generated by a Perlin noise field.
- **Technique**: Recursive fractal drawing using `py5.push_matrix` and `py5.pop_matrix`. The branches grow over time based on the frame count minus depth, allowing the tree to unfold gracefully. The rotation angles of the branches are modified by `py5.os_noise` to simulate a subtle wind. Additive blending creates a neon glow.
- **Description**: An animated sequence of a generative fractal L-System plant.
