# archive_microfiche_drift

## Theme

Forgotten records drift through a scanner gate, turning bureaucratic memory into a phosphor-lit current.

## Technique

This 10-second 60fps animation uses layered microfiche cards, dense unreadable microtext rows, drifting scratches, dust specks, scanner sweep light, and bottom waveform readouts. The palette stays restrained: black-green film stock, phosphor green, amber, and aged cream.

## Outputs

- `archive_microfiche_drift_p1.png` - midpoint preview image
- `archive_microfiche_drift.mp4` - generated animation output
