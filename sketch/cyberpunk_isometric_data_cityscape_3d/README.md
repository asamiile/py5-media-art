# cyberpunk_isometric_data_cityscape_3d

A 3D isometric animation of a bustling cyberpunk data cityscape.

## Theme
A neon-lit cyberpunk motherboard city oscillating with data flow.

## Technique
Rendering a 2D grid of 3D boxes (`py5.box()`) transformed into an isometric projection. The heights of the "buildings" oscillate dynamically using sine waves and Perlin noise. The structures pulse in neon pink, cyan, and deep blue to mimic flowing data lines in a massive metropolis layout.
