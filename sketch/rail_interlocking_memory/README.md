# rail_interlocking_memory

## Theme

A night signal cabinet remembers every permitted route as relay light moving through a rail schematic.

## Technique

This 10-second 60fps animation renders a track-circuit interlocking board with glowing route edges, relay occupancy blocks, signal nodes, moving scan beams, and sparse electrical dust. The palette uses graphite, muted rail steel, cyan, green, amber, and red.

## Outputs

- `rail_interlocking_memory_p1.png` - midpoint preview image
- `rail_interlocking_memory.mp4` - generated animation output
