# Algorithmic Origami Bloom

## Description
Abstract geometric shapes folding and unfolding into each other like hyper-dimensional origami, simulating a blooming mechanical flower.

## Details
- **Format**: Animation (12s @ 60fps)
- **Technique**: 3D rotational matrices applying smooth trigonometric sine waves to nested coordinate systems (push/pop matrix) with transparent filled polygons.
