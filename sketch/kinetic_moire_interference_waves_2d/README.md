# Kinetic Moire Interference Waves 2D

## Concept
A hypnotic optical illusion generated by two overlapping fields of concentric rings. The slight geometric disparities between the grids create a sweeping, macro-scale interference pattern (Moire effect) that moves independently of the actual drawn geometry, playing tricks on the eye.

## Technical Implementation
- Two independent focal points slowly orbiting the center of the canvas in opposing phases.
- 150 concentric circles per focal point, with radiuses extending beyond the 4K canvas diagonals to ensure corner-to-corner coverage.
- Procedurally modulated stroke weights using inverse sine and cosine waves mapped to the phase. This adds a pulsing expansion effect that exacerbates the interference banding.
- High opacity, high contrast vector rendering relying strictly on `py5.circle` overlaps.

## Execution
- `Shapes`: 300 total concentric rings
- `FPS`: 60
- `Duration`: 15 Seconds
- `Resolution`: 3840x2160
