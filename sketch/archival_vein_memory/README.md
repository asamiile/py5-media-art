# archival_vein_memory

An animation of old paper remembering moisture: green-black archival veins creep through three faint fold lines, oxidizing into copper edges as the page slowly darkens.

## Technique

- 10s animation at 60fps.
- 72,000 particles advected through an anisotropic paper-fiber field.
- Low-resolution ink and oxide density fields diffuse and decay each frame, then upscale into the py5 pixel buffer.
- Palette: parchment, sepia ink, oxidized green, and restrained copper edge highlights.
