# kinetic_algorithmic_botanical_fractal_bloom_2d

An algorithmic flower that recursively blooms, folds, and rotates. The branches split recursively into intricate patterns with organic, continuous breathing motion.

## Techniques

A recursive depth-based L-system logic rendered in 2D using `py5` transforms (`push_matrix()`, `pop_matrix()`). Branching angles and lengths are driven by sinusoidal waves that ripple through the depth of the recursion.

## Palette

Deep emerald green bases transitioning to bright bioluminescent pinks and whites at the fractal tips, using additive blending on a dark background.
