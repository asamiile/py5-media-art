# liquid_neon_magnetic_vortex_3d

## Details
- **Date**: 2026-06-05
- **Format**: Animation (10s @ 60fps)
- **Theme**: A 3D simulation of glowing neon liquid magnetic particles swirling into a massive double-vortex.

## Technique
A highly optimized 3D NumPy particle system (15,000 particles) driven by a parameterized dual-attractor force field. Particle colors dynamically map to their orbital velocities as they accelerate into the vortex.
