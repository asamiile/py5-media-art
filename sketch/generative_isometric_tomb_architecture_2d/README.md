# generative_isometric_tomb_architecture_2d

An exploration of ancient, monolithic geometric structures slowly building themselves up block by block, like a forgotten tomb or temple. Built using a 2.5D isometric stacked block generation where blocks are instantiated in layers driven by 2D Perlin noise and cellular automata.

## Tech
- **Library**: py5, NumPy
- **Concept**: Isometric architecture, monolithic structures, block stacking, cellular automata
- **Palette**: Dark sandstone/ochre, deep shadow browns, occasional faint mystical blue glow.
