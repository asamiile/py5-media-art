# abstract_generative_topography_3d

Abstract 3D terrain shifting and forming from data points like an evolving digital landscape.

![Preview](abstract_generative_topography_3d_p1.png)

## Details
- **Date**: 2026-06-20
- **Technique**: A 3D mesh grid whose Z-height is driven by scrolling 2D Perlin noise. The grid is drawn as a wireframe with neon stroke colors.
- **Format**: Animation (10s @ 60fps)
