# kinetic_physics_double_pendulum_chaos_cloud_2d

A visualization of deterministic chaos. 25,000 double pendulums start with infinitesimally small differences in their initial angles, eventually separating into an expanding, swirling chaotic fractal cloud.

## Techniques

Simulates the exact differential equations of motion for 25,000 double pendulums simultaneously using NumPy vectorization. The end effectors are drawn with additive blending.

## Palette

Deep cyan and magenta representing the slight phase differences between the pendulums, creating a glowing cloud of chaos.
