# abstract_cybernetic_optical_fiber_datastreams_2d

An animated 15s sequence of abstract cybernetic optical fiber datastreams in 2D.

## Concept

Thousands of fine glowing optical fibers flowing in a bundle, transmitting neon pulses of data that snake across the screen in 2D space using fluid curves.

## Technique

A particle system where particles leave trailing lines with low opacity. The angle of movement is driven by a 2D Perlin noise flow field, creating coherent sweeping curves. At random intervals, particles draw bright points simulating data packets pulsing along the optical fibers.

## Palette

- Background: Void dark blue (5, 5, 10)
- Fibers: Cyan to magenta gradient 
- Pulses: High-intensity white/blue glow
