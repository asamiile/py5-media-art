# kinetic_reaction_diffusion_coral_growth_2d

A simulated reaction-diffusion system producing Turing patterns that resemble coral or brain-like structures, evolving dynamically over time.

## Tech
- **Library**: py5, NumPy
- **Concept**: Reaction-diffusion, Gray-Scott model, Turing patterns, biology, coral.
- **Palette**: Deep oceanic blue background with bioluminescent cyan, magenta, and white coral structures.
