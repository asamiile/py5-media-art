# generative_magnetic_flux_tubes_3d

Simulating solar magnetic flux tubes twisting and erupting from a central sphere.

## Details

- **Type**: 3D animation
- **Length**: 10 seconds (60fps)

## Technique

Using 3D bezier curves driven by sine-wave offsets to create thick, glowing ribbons of plasma erupting from and returning to a central glowing sphere. Multiple offset curves per tube create a voluminous, energetic plasma look with additive blending.
