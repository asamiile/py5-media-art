# Resonant Void

A visualization of cosmic resonance where gravitational waves vibrate through a shimmering energy field in a deep star-dusted void.

- **Theme**: Cosmic Resonance, spectral energy, beautiful night sky.
- **Technique**: 3D mesh deformation (P3D), harmonic wave superposition, HSB spectral mapping, atmospheric starfield rendering.
- **Palette**: Spectral Shadow (Deep Indigo, Cyan, Amethyst, Pale Gold).

## Description

This piece features a central, vibrating energy membrane that pulses with multiple overlapping harmonic frequencies. The surface is colored based on local displacement and distance from the center, creating a shimmering iridescent effect that shifts between electric cyan and royal amethyst. A dense, static starfield provides a sense of immense scale and depth, situating the resonant structure in a silent celestial void.
