# stellar_clockwork

A generative animation exploring the concept of orbital resonance and the intricate, temporal harmony of the cosmos.

## Concept
The work visualizes the "celestial mechanics" of a complex planetary system. Using nested epicyclic tracers, the piece creates shimmering, silken paths that build up over time into an intricate geometric tapestry. The harmonic synchronization of the orbital speeds suggests an underlying temporal order in a star-dusted night sky.

## Technique
- **Nested Epicyclic Tracers (P2D)**: Multiple layers of rotating orbits are generated, where each center orbits another, creating complex spirograph-like paths.
- **Harmonic Resonance Tuning**: The rotation speeds and radii are related by harmonic ratios, resulting in balanced, intricate geometric patterns.
- **Luminous Trace Accumulation**: Using a high-persistence buffer with additive blending (`py5.ADD`), the shimmering paths build up into silken, thread-like textures over time.
- **Atmospheric Starfield**: A high-density starfield reinforces the cosmic/astronomical context, addressing the "beautiful night sky" request.
