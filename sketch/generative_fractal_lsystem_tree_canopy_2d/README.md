# generative_fractal_lsystem_tree_canopy_2d

A sprawling, procedurally generated fractal tree canopy that continuously grows, branches, and gently sways in a simulated wind. The branching angles and lengths are driven by Perlin noise, creating an organic, glowing bioluminescent forest.

## Tech
- **Library**: py5, NumPy
- **Concept**: L-systems, fractal recursion, noise-driven animation, generative botany.
- **Palette**: Deep twilight blue background with translucent, glowing bioluminescent green and cyan branches.
