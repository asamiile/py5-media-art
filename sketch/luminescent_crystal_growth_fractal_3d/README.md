# luminescent_crystal_growth_fractal_3d

## Description

An animated 15s sequence of a folding 3D luminescent crystal fractal.
The sketch generates a recursive 3D fractal crystal structure that grows dynamically and pulses with color. Recursive 3D drawing is used with `py5.push_matrix()`, `py5.pop_matrix()`, and `py5.box()`, mapping colors to depth, frame_count, and rotation. Lighting and translation add depth and cinematic feel to the 3D scene.
