# kinetic_gray_scott_turbulent_advection_2d

An animated 2D visualization of a Gray-Scott reaction-diffusion system coupled with a chaotic pseudo-noise advection flow field.

## Details

- **Date**: 2026-08-11
- **Theme**: Chemical reaction-diffusion patterns blooming and mutating on a surface, continuously warped and swept away by a turbulent wind field.
- **Technique**: Vectorized Gray-Scott PDE solver combined with semi-Lagrangian grid advection driven by a pseudo-noise flow field (fBm wave superposition). Dynamic bilinear upscaling maps the simulation grid to 4K output resolution, overlaid with a soft border vignette.
- **Color Palette**:
  - Background: Pitch Black Void (`#040406`)
  - Dominant: Bioluminescent Cyan/Teal (`#00f0ff`)
  - Secondary: Deep Amethyst Violet (`#8a2be2`)
  - Accent: Hot White peaks (`#ffffff`)
- **Format**: Animation (60fps)
