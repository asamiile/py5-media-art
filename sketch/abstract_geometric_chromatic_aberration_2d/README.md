# abstract_geometric_chromatic_aberration_2d

Geometric shapes colliding and separating with intense RGB color shifting (chromatic aberration effect).

![Preview](abstract_geometric_chromatic_aberration_2d_p1.png)

## Details
- **Date**: 2026-06-21
- **Technique**: Drawing shapes multiple times with red, green, and blue blend modes slightly offset based on sine wave motion.
- **Format**: Animation (10s @ 60fps)
