# kinetic_cellular_automata_woven_2d

A 1D cellular automata woven into a cylindrical 3D rug structure.

![Preview](kinetic_cellular_automata_woven_2d_p1.png)

## Details
- **Date**: 2026-06-20
- **Technique**: A 1D CA rule generated line by line and wrapped around a cylinder using `py5.points`.
- **Format**: Animation (10s @ 60fps)
