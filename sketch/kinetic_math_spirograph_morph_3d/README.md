# kinetic_math_spirograph_morph_3d

- **Date**: 2026-07-04
- **Type**: Animation (900 frames, 60fps)

## Concept
A complex 3D Fourier series spirograph (Lissajous knot) that breathes, twists, and writhes dynamically as its phase components are continuously modulated over time.

## Techniques
Evaluates a 3D parametric equation with prime number frequencies (11, 41, 107) across 50,000 points per frame, generating a highly dense knot topology. The phase shifts of the sine waves are modulated by the frame count, causing the otherwise static closed-loop fractal to continuously mutate. The massive geometry is drawn using per-vertex HSB continuous spectrum coloring and additive blending, causing intersections to glow brightly. The 3D coordinates are mapped onto 2D using a custom software perspective projection engine.

## Palette
Full glowing neon rainbow spectrum against an absolute black void, resembling a complex laser-light show.
