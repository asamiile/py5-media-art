# kinetic_harmonic_pendulum_web_2d

## Concept
Simulates multiple interconnected pendulums swinging in harmonic motion, tracing continuous silky trails. The glowing trails fade out slowly over time, leaving an intricate, evolving web of light that visualizes complex nested oscillations.

## Technique
The sketch uses partial screen clearing (drawing a semi-transparent black rectangle with very low opacity each frame) to produce heavy motion blur and long, fading trails. 20 distinct points trace complex Lissajous-like paths. These paths are generated by combining 4 cascaded harmonic oscillators for each point, with both their frequencies and phases continuously modulated by smooth Perlin noise. The trails are drawn using additive blending to create intense, overlapping light beams.

## Palette
- **Background**: Pitch black
- **Trails**: High-contrast, neon CMYK-like brights (Cyan, Magenta, Yellow, Spring Green, and White). Additive blending causes these colors to combine into intense, glowing whites where the pendulums cross paths repeatedly.
- **Mood**: Silky, energetic, complex, luminous

## Format
Animation (30 seconds @ 30fps)
