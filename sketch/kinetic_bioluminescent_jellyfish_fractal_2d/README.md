# kinetic_bioluminescent_jellyfish_fractal_2d

A floating, pulsing fractal structure resembling a bioluminescent jellyfish, using recursive trigonometry to create trailing tentacles that respond to a simulated underwater current.

## Techniques

Recursive branching where branch length and angle are modulated by a sine wave (breathing) and Perlin noise (current). Trails are rendered using additive transparent polygons.

## Palette

Pitch black void, glowing cyan and electric blue tentacles, bright pink/magenta core.
