# kinetic_op_art_interference_spiral_2d

An animated 15s sequence showing high-contrast black and white spirals overlapping to form a mesmerizing, pulsating optical illusion.

## Theme
A hypnotic, high-contrast optical illusion inspired by 1960s Op Art, where overlapping geometric rings and spirals interfere to create impossible, pulsating depth.

## Technique
2D drawing of thick, precise black and white vector graphics. Multiple rotating layers of logarithmic spirals and concentric circles. Uses `py5.blend_mode(py5.DIFFERENCE)` to create intense moiré interference patterns as the layers counter-rotate.
