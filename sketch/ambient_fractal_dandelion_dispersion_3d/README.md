# ambient_fractal_dandelion_dispersion_3d

## Details
- **Date**: 2026-06-23
- **Format**: Animation (15s @ 60fps)

## Theme
A fractal dandelion made of luminous seeds blowing apart in a slow-motion wind field, filling the 3D space with drifting, spinning fluff.

## Technique
A 3D sphere packing setup that explodes outward. Each seed is a tiny recursive structure that spins individually, driven by a 3D vector field, fading out as it drifts.

## Visual Impression
A slow-motion explosion of thousands of delicate, glowing seeds caught in an invisible wind.
