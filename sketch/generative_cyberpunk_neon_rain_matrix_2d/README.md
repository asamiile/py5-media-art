# generative_cyberpunk_neon_rain_matrix_2d

## Theme
A stylized, glitching digital rain sequence inspired by cyberpunk aesthetics and the classic Matrix digital rain, replaced with abstract glowing geometric segments.

## Technique
Uses thousands of independent dropping particles with simulated depth (z-index) determining their size, speed, and brightness. High-frequency OpenSimplex noise is sampled as the drops fall to trigger sudden horizontal glitch displacements and color inversions, adding a dynamic, corrupted digital feel. Rendered in a 2D context using semi-transparent background clearing for motion trails.
