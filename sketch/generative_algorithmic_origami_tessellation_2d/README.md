# Generative Algorithmic Origami Tessellation 2D

## Concept
A continuous unfolding and folding of geometric shapes that mimic a massive, breathing origami tessellation, undulating like a landscape.

## Techniques
A hexagonal grid of triangles is constructed, where the vertices move in 3D space driven by 2D Perlin noise. The entire grid is projected isometrically. The faces are drawn with varying opacities and colors based on height to simulate folding and light catching the planes.

## Format
Animation (17 seconds @ 60fps)
