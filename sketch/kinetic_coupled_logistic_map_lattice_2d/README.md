# kinetic_coupled_logistic_map_lattice_2d

An animated 2D visualization of Coupled Map Lattice (CML) dynamics using chaotic logistic map equations and spatial diffusion to form breathing phase boundaries.

## Details

- **Date**: 2026-08-11
- **Theme**: A microscopic tapestry of synchronized chaos, where individual cells oscillate wildly but form unified, breathing structures.
- **Technique**: 2D Coupled Map Lattice (CML) simulation using chaotic logistic map equations ($r = 3.92$) and 4-neighbor spatial diffusion ($e = 0.25$) on wrapping boundaries. Rendered using a custom color mapping where states define the amethyst/cyan gradient and local gradients define the solar gold boundary highlights, upscaled bilinearly.
- **Color Palette**:
  - Background: Charcoal Void (`#0d0d0f`)
  - Dominant: Deep Amethyst Purple (`#9932cc`)
  - Secondary: Luminous Cyan (`#00ffff`)
  - Accent: Solar Gold (`#ffd700`)
- **Format**: Animation (60fps)
