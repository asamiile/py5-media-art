# kinetic_woven_fiber_optic_tapestry_2d

An intricate weaving of glowing fiber-optic threads that undulate like fabric caught in a slow current.

## Tech
- **Library**: py5, NumPy
- **Concept**: Woven fabrics, fiber optics, noise fields, flow patterns.
- **Palette**: Deep abyssal black background with glowing strands of neon cyan, magenta, and pure white light.
