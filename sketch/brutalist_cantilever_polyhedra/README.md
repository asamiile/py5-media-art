# brutalist_cantilever_polyhedra

## Overview
- **Genre**: Architectural / Brutalism / Geometric
- **Composition Archetype**: 3D Sculptural / Volumetric Space (P3D)
- **Motion Archetype**: Poly-Rhythmic Phase Interference
- **Tonal / Palette Family**: Stark Constructivist High-Contrast (`#0f1115`, `#f2efe9`, `#e83424`, `#1c3dd4`, `#f2b018`, `#333841`)

## Concept & Technique
A true `P3D` volumetric sculpture of 180 interlocking cantilevered concrete-bone slabs, signal-vermilion tension beams, ultramarine vertical fins, and cadmium-ochre counterweight blocks floating in stark carbon-black space. Three incommensurable golden-ratio harmonic wave fields ($\omega_1 : \omega_2 : \omega_3 = 1 : \varphi : \varphi^2$) drive poly-rhythmic axial shearing and telescopic cantilever extensions across the 3D assembly.
