# kinetic_chromatic_wave_interference_mesh_2d

A high-density 3D-looking mesh of interlacing sine waves that resembles a digital ocean or topographic map made of glowing string.

## Tech
- **Library**: py5, NumPy
- **Concept**: Wave interference, faux-3D perspective, geometric meshes.
- **Palette**: Synthwave aesthetic—hot pink, electric blue, and deep indigo with additive blending.
