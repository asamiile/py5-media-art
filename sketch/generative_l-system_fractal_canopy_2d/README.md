# generative_l-system_fractal_canopy_2d

**Date**: 2026-07-06
**Type**: Animation (10-30s @ 60fps)

## Concept
A fractal canopy generated by an L-system grows over time. The branching angles slowly sway as if blown by a gentle breeze. As it grows, the colors transition from deep wood browns at the base to vibrant autumn leaf colors at the tips.

## Techniques
A recursive tree drawing function. The recursion depth and wind angle are animated over time using Perlin noise.

## Palette
Autumn forest. Deep espresso brown, burnt orange, goldenrod, and crimson on a soft cream background.
