# kinetic_abstract_vector_field_wheat_waves_2d

Thousands of tiny lines (vectors) arranged in a dense grid, all rotating according to an evolving procedural noise vector field, creating a visual effect similar to a field of wheat waving in the wind.

## Techniques

Computes a fast 2D procedural noise field using combining sine and cosine functions. Maps the resulting angles to line orientations and colors, drawn efficiently via `py5.begin_shape(py5.LINES)`.

## Palette

"Golden Hour" palette: rich gold, amber, and deep brown, glowing against a dark background with a slight fade trail.
