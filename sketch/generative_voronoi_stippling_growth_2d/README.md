# generative_voronoi_stippling_growth_2d

A mathematical stippling growth pattern based on an evolving Delaunay triangulation.

## Details

- **Type**: 2D animation
- **Length**: 10 seconds (60fps)

## Technique

An animated sequence that starts with a few seed points and organically spawns new points over time in the largest empty circles, giving a cellular or bacterial growth appearance. Rendered purely as points and connecting lines (Delaunay triangulation) in monochrome.
