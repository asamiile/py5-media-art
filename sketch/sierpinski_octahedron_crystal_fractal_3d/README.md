# sierpinski_octahedron_crystal_fractal_3d

## Theme
A mathematically pure, recursively subdivided Sierpinski Octahedron that slowly rotates, while emitting pulsing geometric light from its core like an intricate magical crystal.

## Technique
Generating a 3D fractal structure through a 5-level recursive function. This creates 7,776 individual translucent octahedrons in 3D space. The global time phase elegantly drives the rotation, as well as a "breathing" sine wave function that pushes the vertices of the fractal outward slightly, making the crystal look as though it's alive and continuously oscillating.

## Color palette
- Background: Very dark obsidian/amethyst black
- Dominant: Translucent Amethyst / Purple
- Secondary: Glowing hot pink core
- Mood: Crystalline / Magical / Mathematical

## Format
Animation (10s @ 60fps)
