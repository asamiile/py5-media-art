# kinetic_particle_string_theory_vibrations_2d

**Date**: 2026-07-07
**Type**: Animation (10-30s @ 60fps)

## Concept
A visual representation of string theory vibrations. Thousands of extremely thin, glowing "strings" (lines) connect in a dense network. Each string vibrates with its own harmonic frequency. The overall structure slowly rotates and morphs between higher-dimensional projections.

## Techniques
Creates a network of nodes on a 3D torus. The connection lines between nodes are not straight, but drawn as high-frequency sine waves using `py5.begin_shape(py5.LINE_STRIP)`. The amplitude and phase of the vibration depends on the distance and orientation in the network.

## Palette
Quantum entanglement. Pitch black void. The vibrating strings are thin, intensely glowing electric blue, neon violet, and pure white.
