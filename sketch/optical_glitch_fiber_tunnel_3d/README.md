# Optical Glitch Fiber Tunnel 3D

## Description
A high-speed journey along an endless, glitching optical fiber cable illuminating deep subterranean caverns. The animation conveys a sense of high-speed data transfer passing through an organic underground network.

## Technical Details
- **Format:** Animation (10s @ 60fps)
- **Palette:** Very dark blue void with shifting neon blue and cyan highlights.
- **Algorithm:** 3D generative tunnel using `py5.curve_vertex` points displaced by 1D noise, with neon light pulses traveling down the tunnel path using high-speed phase offsets.
- **Renderer:** py5.P3D with HSB additive-like stroke brightness mapping.
