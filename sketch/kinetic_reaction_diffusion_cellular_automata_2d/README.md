# kinetic_reaction_diffusion_cellular_automata_2d

**Date**: 2026-07-06
**Type**: Animation (10-30s @ 60fps)

## Concept
A reaction-diffusion simulation where two chemicals interact to form organic stripes and spots.

## Techniques
Gray-Scott model simulation on a numpy grid, rendered as an upscaled pixel array in py5. 

## Palette
Bioluminescent alien flora. Deep dark background with glowing cyan and neon pink patterns based on chemical concentration.
