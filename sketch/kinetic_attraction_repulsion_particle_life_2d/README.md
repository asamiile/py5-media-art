# kinetic_attraction_repulsion_particle_life_2d

"Particle Life" or simulated artificial chemistry. 4 different colors of particles interact with specific attraction and repulsion forces, creating emergent structures like crawling worms, spinning cells, and crystal lattices.

## Techniques

O(N^2) simulation over 4800 particles using numpy to calculate pairwise distances. Softened inverse square forces based on a 4x4 interaction matrix.

## Palette

Neon Pink, Cyan, Yellow, and Purple against a dark space background.
