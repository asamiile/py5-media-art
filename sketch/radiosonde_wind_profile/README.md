# radiosonde_wind_profile

## Theme

A weather balloon translates a dark atmosphere into pressure, wind, and temperature memory.

## Technique

This 10-second 60fps animation renders a skewed atmospheric sounding chart with animated temperature/dewpoint traces, a rising balloon path, drifting moisture layers, wind barbs, and telemetry waveforms.

## Outputs

- `radiosonde_wind_profile_p1.png` - midpoint preview image
- `radiosonde_wind_profile.mp4` - generated animation output
