# Generative Algorithmic Fractal Tree Roots 2D

## Concept
A massive network of organic roots or lightning branches expanding outward across the canvas, searching for connection points using a continuous space colonization algorithm.

## Techniques
A highly optimized numpy grid simulating the Space Colonization Algorithm using SciPy's KDTree. Points are randomly placed in a circular radius acting as "nutrients", and branches grow toward the nearest points organically, forming a sprawling fractal network.

## Format
Animation (19 seconds @ 60fps)
