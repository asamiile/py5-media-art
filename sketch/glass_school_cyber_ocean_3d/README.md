# glass_school_cyber_ocean_3d

![Preview](glass_school_cyber_ocean_3d_p1.png)

## Concept

A hypnotic 3D simulation of a massive school of geometric glass fish swimming through a glowing liquid cyber-ocean.

## Execution

- **Technique**: 3D geometric fish with rotation driven by velocity, constrained in a space. Swimming direction influenced by a 3D Simplex noise vector field.
- **Format**: Animation (15s @ 60fps)

## Files

- `main.py` - Primary script
- `glass_school_cyber_ocean_3d_p1.png` - Visual preview
- `glass_school_cyber_ocean_3d.mp4` - Animation output (Not tracked in git)
