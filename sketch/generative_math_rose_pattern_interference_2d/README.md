# Generative Math Rose Pattern Interference 2D

## Concept
Mathematical rose curves ($r = \cos(k\theta)$) that shift their $k$ parameters continuously, creating intricate blooming flower-like interference patterns that rotate and overlap.

## Techniques
High-resolution arrays (10,000 points) are evaluated natively using NumPy trigonometric functions. The parameters of six overlapping roses drift in a fluid motion using py5's noise and time variables. Additive blending generates bright, luminous interference nodes.

## Format
Animation (28 seconds @ 60fps)
