## Concept
Sumi-e ink drops on washi paper simulated via 60k particles per drop diffusing along paper fiber direction; variable concentration creates tonal range from dilute wash to dense pools; nearby drops connect through flowing tendrils; satellite spatters add authentic imperfection.
