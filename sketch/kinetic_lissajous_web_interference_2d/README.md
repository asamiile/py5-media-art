# kinetic_lissajous_web_interference_2d

**Date**: 2026-07-21
**Type**: Animation (900 frames, 60fps)

## Concept
Complex geometric webs created by interfering Lissajous curves that slowly phase shift over time, drawing a luminous wireframe structure.

## Techniques
150 layered Lissajous curves tracing out complex shapes. Each layer has a slightly different phase and frequency, leaving faint trails with additive blending that build up into a dense moiré interference pattern in the center.

## Palette
Monochromatic gold/amber (r=255, g=110-250, b=0-100) on a dark charcoal background.
