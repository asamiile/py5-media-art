# diel_migration_sonar

## Theme

A living deep-ocean scattering layer rises through darkness as if the water column is breathing.

## Technique

This 10-second 60fps animation uses a procedural sonar display: thousands of drifting organisms follow a seamless vertical migration curve, density bands fold through sine-driven currents, and acoustic sweep rings reveal the layer in pulses. Small diagnostic traces and restrained amber/coral signals keep the piece legible without washing the image to white.

## Outputs

- `diel_migration_sonar_p1.png` - midpoint preview image
- `diel_migration_sonar.mp4` - generated animation output
