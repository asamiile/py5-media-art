# sashiko_terracotta_drift

## Overview
- **Genre**: Textile / Calligraphy / Procedural Craft
- **Composition Archetype**: Full-Bleed Continuous Field
- **Motion Archetype**: Multi-Act Temporal Evolution
- **Tonal / Palette Family**: High-Key Mineral & Washi (`#ede8dc`, `#e3ddce`, `#263640`, `#ba4a30`, `#ca8628`, `#46726a`)
- **Format**: Animation (24s @ 60fps, 3840×2160)

## Concept & Technique
An edge-to-edge procedural craft field of layered boro linen patchwork and hitomezashi sashiko running stitches across a full-canvas warm alabaster-linen ground (`#ede8dc`). Across a 4-act temporal progression, warp, weft, and diagonal stitch lattices in iron-gall slate, burnt terracotta, raw mineral ochre, and celadon sage nucleate, expand, billow through traveling shear waves, and settle into taut woven equilibrium.
