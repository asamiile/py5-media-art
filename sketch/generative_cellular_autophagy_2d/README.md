# generative_cellular_autophagy_2d

An abstract cellular simulation inspired by autophagy (GO:0006914), where larger cellular bodies systematically digest smaller internal materials to remodel themselves.

## Details

- **Type**: 2D animation
- **Length**: 10 seconds (60fps)

## Technique

A soft-body physics simulation using noise-driven membranes and attraction forces. 'Macromolecular' yellow-green particles are pulled into and dissolved by a larger wandering central vacuole-like entity, diminishing their alpha and size upon being consumed.
