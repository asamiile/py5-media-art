# cybernetic_data_monolith_glitch_3d

## Details
- **Date**: 2026-06-03
- **Format**: Animation (15s @ 60fps)
- **Theme**: A monolithic, imposing brutalist cybernetic structure covered in flowing streams of data points, with periodic horizontal scanline glitches and displacement waves traversing its surface.
- **Technique**: 3D Box geometry modified dynamically by pushing vertices along their normals based on a noise threshold and time, combined with texture-like data points generated via a particle system clinging to the faces. To avoid complex vertex manipulation, the monolith is built from many smaller boxes to allow dynamic displacement on a grid.
- **Color palette**:
  - Background: Pitch black
  - Dominant (60%): Brutalist concrete grey
  - Secondary (30%): Hacker green
  - Accent (10%): Glitch magenta
  - Mood: dystopian / hacker

## Description
An animated 3D simulation of a massive brutalist data structure slowly rotating. A sweeping horizontal scanline intermittently glitches out sections of the wall, shifting colors to magenta and green while scattering geometry. Glowing data nodes emerge and retreat based on an underlying 3D noise field.
