# generative_magnetic_core_containment_3d

## Details
- **Date**: 2026-06-23
- **Format**: Animation (15s @ 60fps)

## Theme
A high-energy magnetic containment field holding a violently shifting plasma core. The containment rings rotate, while the core plasma tries to escape, shooting out solar-flare-like arcs.

## Technique
3D torus rings combined with a dense particle system in the center. The particles are constrained by a boundary distance function and deformed by 3D Perlin noise.

## Visual Impression
A blazing miniature sun trapped inside a futuristic, spinning magnetic cage.
