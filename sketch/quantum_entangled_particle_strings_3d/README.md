# quantum_entangled_particle_strings_3d

## Details
- **Date**: 2026-06-05
- **Format**: Animation (12s @ 60fps)
- **Theme**: A 3D simulation of glowing quantum strings snapping together with intense light when they become entangled.

## Technique
Procedurally generated 3D splines. Distances between nodes are tracked using NumPy, rendering bright lines when nodes get close to each other.
