# library_stack_luminance

## Theme

A quiet library stack remembers circulation as shelf light, call numbers, and scanner traces.

## Technique

This 10-second 60fps animation renders dense shelf rows, shifting call-number blocks, a moving scanner beam, checkout arcs, dust, and environmental traces. The palette combines graphite, paper cream, cyan, amber, rose, and green.

## Outputs

- `library_stack_luminance_p1.png` - midpoint preview image
- `library_stack_luminance.mp4` - generated animation output
