# biomechanical_fractal_spores_3d

## Details
- **Date**: 2026-06-03
- **Format**: Animation (15s @ 60fps)
- **Theme**: Microscopic spores that resemble both organic cells and metallic fractal structures, drifting and colliding to form larger colonies.
- **Technique**: 3D fractal generation (Mandelbulb-like recursive spheres) combined with soft body physics and collision detection, rendered with deep sea bioluminescence colors.
- **Color palette**:
  - Background: Deep abyss blue
  - Dominant (60%): Bioluminescent cyan
  - Secondary (30%): Toxic neon green
  - Accent (10%): Pale pink
  - Mood: organic/alien

## Description
An animated 3D macro simulation of biomechanical fractal spores drifting through a dark abyss, glowing with cyan, neon green, and pale pink bioluminescence.
