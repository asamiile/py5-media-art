# kinetic_majorana_anyon_braiding_2d

A 2D kinetic simulation of non-Abelian anyon braiding, topological Berry phase singularities, and chiral Majorana edge currents in a fractional quantum Hall / $p+ip$ topological superconductor thin film.

## Concept & Physics

In two-dimensional topological phases of matter—such as the Moore-Read $\nu = 5/2$ fractional quantum Hall state or chiral $p+ip$ topological superconductors—quasiparticles do not obey conventional Fermi-Dirac or Bose-Einstein statistics. Instead, quantized vortex cores host localized zero-energy Majorana fermion modes:
$$\gamma_i = \gamma_i^\dagger, \quad \{\gamma_i, \gamma_j\} = 2\delta_{ij}$$

When two vortex cores exchange positions via an adiabatic braiding path, the quantum many-body state undergoes a non-Abelian unitary transformation generated by the braid group $B_n$:
$$R_{ij} = \exp\left(\frac{\pi}{4}\gamma_i \gamma_j\right) = \frac{1}{\sqrt{2}}(1 + \gamma_i \gamma_j)$$

This work visualizes:
1. **Majorana Zero Mode (MZM) Braiding**: 6 vortex cores organized in 3 coupled pairs execute harmonic Lissajous and trefoil exchange dances, demonstrating topological quantum logic operations protected from local decoherence.
2. **Topological Berry Phase Singularities**: Complex phase winding $\Phi(x, y) = \sum_{i=1}^6 q_i \arg(z - z_i)$ produces winding branch cuts and interference fringes across the superconducting order parameter amplitude field.
3. **Dual-Light Blinn-Phong Specular Chrome Shading**: Vectorized finite-difference surface normals evaluated from the order parameter height field $h(x, y)$ illuminated by opposing cyan and amber light vectors.
4. **Spacetime Worldline Ribbons**: Fading luminous history trails that trace the worldline braids through 2D+1 spacetime projection.
5. **Chiral Boundary Edge States**: 1,400 Lagrangian particles streaming unidirectionally along the quantum Hall mesa boundary with dispersion velocity $v_{edge}$.
6. **Topological Fusion Channel Sparks**: Microscopic energy flashes and fermion sparks released at anyon periapsis during exchange operations ($\sigma \times \sigma = \mathbf{1} + \psi$).
