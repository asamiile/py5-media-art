# kinetic_fluid_dynamics_particles_2d

A swirling simulation of fluid dynamics where 15,000 glowing particles trace the vector field of a simulated fluid, leaving fading trails.

## Tech
- **Library**: py5, NumPy
- **Concept**: Fluid vector fields, glowing trails.
- **Techniques**: 2D Perlin noise vector field guiding semi-transparent particles over time with additive blending. Fading trails are created by drawing a low-opacity background rectangle each frame.
- **Palette**: Deep oceanic colors (teal, aqua, and cyan) with glowing trails on a deep dark indigo background.
