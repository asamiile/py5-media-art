# kinetic_forest_fire_stochastic_percolation_2d

A 4K kinetic simulation of a forest fire front propagating across a forest canopy under wind-driven advection, solved using coupled reaction-diffusion-advection partial differential equations.

## Simulation Details

- **Reaction-Diffusion-Advection PDE**: Integrates three coupled fields:
  - **Biomass ($B$)**: Represents forest fuel density, consumed where temperature is high.
  - **Temperature ($T$)**: Spreads via heat diffusion and is advected downwind.
  - **Smoke ($S$)**: Generated by combustion and drifts rapidly with the wind.
- **Upwind Advection Scheme**: First-order upwind scheme models wind drift vector $\mathbf{W} = (1.6, 0.8)$ stably.
- **Organic Color Blend**: Upscaled to 4K using bilinear interpolation. The color map blends unburned biomass (dark pine teal) into active fire fronts (crimson-orange-yellow gradients) and consumed fuel (black void), covered by soft ash-grey smoke.

## Run

To run the simulation and render the 20-second animation:

```bash
uv run python sketch/kinetic_forest_fire_stochastic_percolation_2d/main.py
```
