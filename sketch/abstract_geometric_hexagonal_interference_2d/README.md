# abstract_geometric_hexagonal_interference_2d

An animated 15s sequence of abstract geometric hexagonal interference in 2D.

## Concept

A pulsing, shifting grid of hexagons that overlap to create moiré interference patterns, with a sweeping neon gradient passing over them.

## Technique

Generating a dense 2D hexagonal grid and drawing multiple layers of slightly offset hexagons that rotate slowly in opposite directions. The interference creates larger-scale optical illusions. 

## Palette

- Background: Void dark blue (0, 0, 5)
- Hexagons: Full color spectrum shifting over time
