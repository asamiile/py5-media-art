# electrowetting_lens_array

Voltage pulses flatten tiny droplets on a conductive glass slide, turning each droplet into a shifting micro-lens that bends pale caustic lines through the dark substrate.

- **Format**: Animation, 10 seconds at 60fps
- **Technique**: Vectorized electrowetting lens-field animation with pulsed elliptical droplets, rim highlights, caustic interference bands, electrode traces, and voltage memory rendered through the py5 pixel buffer.
- **Palette**: Graphite glass, oil-blue substrate, aquamarine caustics, silver rims, and restrained amber voltage traces.
