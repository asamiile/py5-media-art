# generative_floral_spirograph_mandala_2d

An animated 20s sequence of a blooming, intricate floral mandala composed of thousands of intersecting spirograph lines.

## Theme
A slow-blooming, intricate floral mandala composed of thousands of intersecting spirograph lines.

## Technique
2D parametric equations for a hypotrochoid and epitrochoid combined. A massive array of `py5.vertex` points is generated procedurally with slowly rotating phases to give a blooming effect, with Perlin noise added for subtle organic wobble.
