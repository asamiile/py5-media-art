# ambient_neural_action_potential_3d

Visualizing action potentials propagating through a complex 3D neural network (inspired by GO:0001508 - action potential).

## Details

- **Type**: 3D animation
- **Length**: 10 seconds (60fps)

## Technique

A 3D nearest-neighbor graph is constructed from 200 nodes within a spherical volume. A continuous flowing sine wave based on the Y-axis position and time creates bright, pulsing waves that cascade through the network's connections. Additive blending enhances the glowing, ambient aesthetic of the action potentials firing.
