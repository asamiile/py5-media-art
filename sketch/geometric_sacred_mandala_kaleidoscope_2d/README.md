# geometric_sacred_mandala_kaleidoscope_2d

A slowly blooming 2D sacred geometry mandala using kaleidocopic transformations.

## Theme
A slowly blooming geometric mandala in kaleidocopic space.

## Technique
Using `py5.push_matrix()`, `py5.rotate()`, and `py5.scale()` in a loop to draw symmetrical layers of geometric shapes (triangles, circles, lines). The shapes expand and contract using `sin()` waves over time. Colors cycle smoothly through the HSB spectrum.
